Fitness tracker application

Individual coursework, Introduction to Software Development

A Java program that turns a distance in kilometres into a step count and prints step statistics in plain English, for example “3 thousands, 4 hundreds and 5 tens”. It comes with a written report explaining the design and testing.

Technologies
Java, object-oriented programming, console input with Scanner
My role
I designed and wrote all three classes and the report: StepStats stores and formats the data, Distance does the conversion, and UserInterfaceMain handles the menu.
Challenge and learning
Getting the formatting right: leaving out zero values, choosing singular or plural words, and placing commas and “and” correctly. I also learned why keeping each class to one job makes code easier to test.

KNN breast tumour classification

Group report, team of 3

A written analysis proposing K-nearest neighbours as an alternative model for classifying breast tumours as benign or malignant, using the Wisconsin Diagnostic Breast Cancer dataset. This is a design proposal and was not built as a working system.

Technologies
Machine-learning concepts: data cleaning, feature scaling, stratified splits, tuning k, and metrics including recall, F1-score and ROC-AUC
My role
I wrote the alternative-model section, including how KNN should be compared with the group’s baseline model.
Challenge and learning
Explaining why a missed malignant tumour matters more than a false alarm, so recall is the key measure. I learned to scale data using the training set only, so no information leaks into testing, and to state limits clearly: real clinical use would need testing and professional supervision.
